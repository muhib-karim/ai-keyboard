# AI Keyboard — Discord Announcement

## Discord Announcement

---

🎉 **AI Keyboard v1.0.0 is Now Live!** 🎉

Introducing **AI Keyboard** — the first Android keyboard with fully offline AI voice typing powered by user-selectable models!

### 🔒 Privacy-First
- 100% offline voice processing
- No cloud servers
- No data tracking
- Your voice stays on your device

### 🤖 User-Selectable Models
- NVIDIA Parakeet 0.6B (best accuracy)
- Distil-Whisper ONNX (fast)
- Vosk (lightweight)
- Install any ONNX or Vosk model

### ✨ Features
- Smart auto-correct & predictions
- Swipe/gesture typing
- Emoji, GIF, stickers
- Clipboard manager
- Custom themes
- Material 3 design
